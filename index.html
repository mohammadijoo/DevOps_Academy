Learning design

Built for engineers who learn by operating systems.

Lessons favor reproducible commands, visible state changes, failure analysis, and small labs over passive feature lists.

01

Concept → command

Understand the operating model first, then apply it through focused commands and configuration.

02

Observe the state

Inspect files, processes, logs, pipelines, deployments, and metrics before changing them.

03

Break and recover

Troubleshooting labs turn common failure modes into repeatable diagnostic workflows.

04

Connect the toolchain

Capstones show how individual tools participate in one delivery system rather than isolated demos.
