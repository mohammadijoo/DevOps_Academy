Course brief

A complete Salt Project curriculum for high-speed remote execution, declarative configuration, event-driven automation, orchestration, and resilient fleet operations.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Operate Salt masters, minions, SSH workflows, and secure key exchange
  • Build idempotent states with pillars, grains, Jinja, requisites, and formulas
  • Use targeting, orchestration, reactors, beacons, runners, returners, and the event bus
  • Extend Salt with custom modules, states, engines, plugins, and APIs
  • Design secure, highly available, scalable Salt infrastructure for large fleets

Complete syllabus

40 chapters in prerequisite order.

The structure goes beyond a command reference and includes architecture, security, reliability, troubleshooting, automation, governance, and production operations.
