Course brief

A practical build-engineering curriculum covering both Maven and Gradle from fundamentals to enterprise scale.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Model reliable JVM builds using Maven and Gradle conventions
  • Control dependencies, repositories, plugins, toolchains, testing, and publishing
  • Scale multi-module and composite builds while improving build performance
  • Harden dependency resolution with locking, verification, signatures, and provenance
  • Integrate builds into CI/CD and migrate safely between build-tool generations

Complete syllabus

31 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
