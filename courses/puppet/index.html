Course brief

A rigorous Puppet curriculum covering declarative configuration, reusable modules, centralized operation, orchestration, testing, security, and enterprise lifecycle management.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Model desired state with Puppet resources, classes, modules, and catalogs
  • Design reusable configuration with Hiera and the roles/profiles pattern
  • Operate Puppet agents, servers, certificates, environments, and PuppetDB
  • Extend and test Puppet through custom code, Bolt, CI/CD, and quality tooling
  • Understand modern Puppet Core, Puppet Enterprise, scaling, migration, and security

Complete syllabus

37 chapters in prerequisite order.

The structure goes beyond a command reference and includes architecture, security, reliability, troubleshooting, automation, governance, and production operations.
