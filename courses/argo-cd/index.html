Course brief

A production-grade Argo CD curriculum for declarative Kubernetes delivery, multi-cluster GitOps, governance, security, and resilient platform operations.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Explain GitOps reconciliation and Argo CD architecture
  • Model Applications, Projects, repositories, sync policies, and health
  • Use ApplicationSets and multi-source patterns for fleet-scale delivery
  • Secure Argo CD with RBAC, SSO, signatures, secrets, and policy
  • Operate Argo CD with HA, observability, upgrades, backup, and disaster recovery

Complete syllabus

40 chapters in prerequisite order.

The structure goes beyond a command reference and includes architecture, security, reliability, troubleshooting, automation, governance, and production operations.
