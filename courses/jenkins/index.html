Course brief

A complete Jenkins curriculum for reliable Pipeline-as-Code and production automation.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Install, secure, configure, and operate a modern Jenkins controller and agent fleet
  • Author Declarative and Scripted Pipelines with reusable libraries and resilient execution patterns
  • Run workloads on static, Docker, and Kubernetes agents while managing credentials safely
  • Automate Jenkins configuration with JCasC, Job DSL, APIs, and repeatable infrastructure practices
  • Monitor, tune, upgrade, back up, recover, and troubleshoot Jenkins in production

Complete syllabus

41 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
