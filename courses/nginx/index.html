Course brief

A complete NGINX curriculum for high-performance web serving, reverse proxying, traffic management, TLS termination, caching, security, and resilient production delivery.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Configure NGINX safely and understand its event-driven worker architecture
  • Serve static content and proxy HTTP, WebSocket, gRPC, FastCGI, and application traffic
  • Design TLS, HTTP/2, HTTP/3, caching, rate limiting, and load-balancing policies
  • Operate NGINX for TCP/UDP services, Kubernetes, observability, and zero-downtime changes
  • Harden, tune, troubleshoot, and scale NGINX in production

Complete syllabus

44 chapters in prerequisite order.

The structure goes beyond a command reference and includes architecture, security, reliability, troubleshooting, automation, governance, and production operations.
