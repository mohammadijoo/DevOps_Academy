Course brief

A comprehensive GitHub Actions curriculum from YAML workflow fundamentals to secure reusable delivery platforms, scalable runners, provenance, and enterprise automation.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Author reliable event-driven CI/CD workflows and reusable automation
  • Use matrices, artifacts, caches, environments, services, and runner strategies effectively
  • Secure workflows with least privilege, OIDC, pinned dependencies, and attestations
  • Operate self-hosted and autoscaled runner infrastructure
  • Design governed organization-wide delivery platforms with observability and cost controls

Complete syllabus

36 chapters in prerequisite order.

The structure moves from fundamentals through architecture, automation, security, reliability, troubleshooting, scaling, and production operations.
