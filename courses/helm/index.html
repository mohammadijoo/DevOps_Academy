Course brief

A complete Helm curriculum for maintainable Kubernetes packaging and release engineering.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Design clean, reusable charts with values, templates, helpers, dependencies, and schema validation
  • Operate releases safely with install, upgrade, rollback, hooks, tests, and failure handling
  • Package and distribute charts through OCI registries with provenance and supply-chain controls
  • Integrate Helm into CI/CD and GitOps without hiding Kubernetes operational behavior
  • Migrate Helm estates toward Helm 4 and troubleshoot complex production chart deployments

Complete syllabus

35 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
