Course brief

A complete GitLab curriculum spanning source management, CI/CD, DevSecOps, and platform operations.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Operate GitLab projects, groups, merge requests, planning, and governance workflows
  • Design efficient pipelines with runners, DAGs, reusable components, and environments
  • Use registries, releases, security scanners, vulnerability management, and policies
  • Automate GitLab with APIs, webhooks, tokens, and Kubernetes integrations
  • Administer and troubleshoot self-managed GitLab with backup, upgrade, HA, and audit practices

Complete syllabus

34 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
