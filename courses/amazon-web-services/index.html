Course brief

A comprehensive AWS curriculum for DevOps engineers building secure, automated, observable, resilient, and cost-aware cloud platforms.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Design AWS accounts, identities, networks, compute, storage, and application platforms
  • Build delivery pipelines with AWS-native and GitHub-based automation
  • Provision infrastructure with CloudFormation, CDK, Terraform, and policy controls
  • Operate workloads with CloudWatch, Systems Manager, CloudTrail, Config, and security services
  • Design resilient multi-account production environments using AWS Well-Architected principles

Complete syllabus

58 chapters in prerequisite order.

The structure goes beyond a service catalog and includes architecture, identity, security, networking, delivery, observability, reliability, governance, automation, cost, troubleshooting, and production operations.
