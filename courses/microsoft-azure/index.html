Course brief

A comprehensive Microsoft Azure curriculum for DevOps engineers building governed, automated, observable, secure, resilient, and cost-efficient cloud platforms.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Design Azure tenants, subscriptions, identity, networking, compute, storage, and application platforms
  • Automate infrastructure using Bicep, ARM, Terraform, Azure CLI, and PowerShell
  • Build CI/CD with Azure Pipelines, GitHub Actions, artifacts, and deployment environments
  • Operate workloads with Azure Monitor, Log Analytics, Application Insights, Policy, and Defender
  • Apply Azure Well-Architected, landing-zone, resilience, security, and FinOps practices

Complete syllabus

58 chapters in prerequisite order.

The structure goes beyond a service catalog and includes architecture, identity, security, networking, delivery, observability, reliability, governance, automation, cost, troubleshooting, and production operations.
