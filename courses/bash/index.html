Course brief

A complete Bash automation curriculum for DevOps engineers.

This course is organized as a progressive operational curriculum. Chapter 1 is fully published in this package, while later lesson paths are reserved in curriculum.json so the course can grow without changing URLs or navigation.

By the end

You will be able to

  • Write predictable Bash scripts with disciplined quoting and argument handling
  • Compose pipelines, functions, text tools, files, processes, and network commands safely
  • Handle failures with explicit exit status, strictness, traps, cleanup, retries, and logging
  • Automate CI/CD, containers, APIs, remote systems, and common DevOps CLIs
  • Test, lint, secure, profile, and maintain production shell automation

Complete syllabus

20 chapters in prerequisite order.

The structure is deliberately broader than shell syntax. It covers portability, reliability, security, testing, CI/CD, APIs, remote operations, performance, and production design patterns.
