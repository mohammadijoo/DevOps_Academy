Course brief

A comprehensive Kubernetes curriculum from first Pod to production cluster engineering.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Understand Kubernetes control-plane architecture, declarative APIs, reconciliation, and workload controllers
  • Operate applications with Services, Gateway/Ingress, storage, scheduling, autoscaling, and disruption controls
  • Apply RBAC, admission, Pod Security, NetworkPolicy, encryption, and software-supply-chain safeguards
  • Install, upgrade, back up, observe, troubleshoot, and scale Kubernetes clusters safely
  • Extend Kubernetes with CRDs, operators, webhooks, and production platform patterns

Complete syllabus

46 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
