Course brief

A rigorous distributed version-control curriculum for modern delivery teams.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Understand Git’s object model, index, refs, and distributed architecture
  • Design safe branch, merge, rebase, release, and collaboration workflows
  • Recover lost work and investigate regressions using Git’s forensic tools
  • Secure repository history, credentials, signatures, and sensitive data
  • Operate Git efficiently in monorepos, CI/CD pipelines, and GitOps systems

Complete syllabus

26 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
