Course brief

A rigorous distributed version-control curriculum for modern delivery teams.

This course is organized as a progressive operational curriculum. Lesson files are already reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Understand Git’s object model and distributed architecture
  • Design safe branch, merge, rebase, and release workflows
  • Recover lost work using reflog and repository diagnostics
  • Secure commits, credentials, and repository history
  • Use Git as the foundation for CI/CD, infrastructure code, and GitOps

Complete syllabus

16 chapters in prerequisite order.

The structure is deliberately broader than a command reference. It includes architecture, security, reliability, troubleshooting, automation, and realistic operational workflows.
