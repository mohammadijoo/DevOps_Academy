Course brief

A production-oriented Chef curriculum for declarative configuration, reusable policy, infrastructure testing, compliance, and enterprise fleet operations.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Model desired state with Chef resources, recipes, cookbooks, and custom resources
  • Manage attributes, Ohai data, templates, files, notifications, and idempotent convergence
  • Build reproducible policy with Policyfiles and govern cookbook dependencies
  • Test and secure infrastructure code with Test Kitchen, ChefSpec, Cookstyle, and InSpec
  • Operate Chef Infra Server, automate fleets, scale safely, and recover production environments

Complete syllabus

38 chapters in prerequisite order.

The structure goes beyond a command reference and includes architecture, security, reliability, troubleshooting, automation, governance, and production operations.
