Course brief

A complete Robot Framework curriculum covering readable acceptance tests, reusable automation architecture, custom libraries, CI integration, and large-suite operations.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Write maintainable keyword-driven tests and tasks
  • Build reusable resources, variables, templates, and custom libraries
  • Integrate browser, API, process, filesystem, and database automation
  • Scale execution, reporting, and parallelism in CI/CD
  • Design governance and debugging practices for large Robot Framework estates

Complete syllabus

30 chapters in prerequisite order.

The structure moves from fundamentals through architecture, automation, security, reliability, troubleshooting, scaling, and production operations.
