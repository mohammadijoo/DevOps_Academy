Course brief

A complete Docker curriculum from first container to secure production container workflows.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Understand Docker Engine, OCI images, container isolation, layers, and runtime architecture
  • Build reproducible, cache-efficient, multi-platform images with BuildKit and multi-stage Dockerfiles
  • Design Compose applications, networking, storage, resource controls, and operational health checks
  • Harden containers with least privilege, rootless operation, scanning, SBOMs, and signed provenance
  • Integrate Docker into registries, CI/CD, automation, and production incident-response workflows

Complete syllabus

42 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
