Course brief

A complete Linux operations curriculum for DevOps engineers.

This course is organized as a progressive operational curriculum. Lesson files are already reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Operate Linux confidently from the command line
  • Manage files, identities, processes, services, storage, and networks
  • Automate reliable operational tasks with Bash
  • Monitor, harden, troubleshoot, and recover Linux systems
  • Prepare hosts for CI runners, containers, and production workloads

Complete syllabus

20 chapters in prerequisite order.

The structure is deliberately broader than a command reference. It includes architecture, security, reliability, troubleshooting, automation, and realistic operational workflows.
