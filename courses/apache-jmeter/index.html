Course brief

A rigorous performance-testing curriculum from basic test plans to distributed load generation, telemetry, bottleneck analysis, and production-grade performance engineering.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Design realistic load, stress, spike, soak, and capacity tests
  • Build maintainable JMeter plans with correlation and parameterization
  • Run large tests safely in CLI and distributed modes
  • Export telemetry and interpret latency, throughput, saturation, and error behavior
  • Automate performance gates in CI/CD and operate scalable load infrastructure

Complete syllabus

35 chapters in prerequisite order.

The structure moves from fundamentals through architecture, automation, security, reliability, troubleshooting, scaling, and production operations.
