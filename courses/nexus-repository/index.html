Course brief

A production-focused Nexus Repository curriculum for package management, artifact governance, and resilient delivery.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Design hosted, proxy, and group repositories for multiple package ecosystems
  • Secure users, roles, content, tokens, identity providers, and network access
  • Automate repository operations with APIs, tasks, webhooks, and CI/CD integrations
  • Plan cleanup, backup, migration, upgrades, HA, observability, and capacity
  • Use Nexus Repository as a controlled software-supply-chain boundary

Complete syllabus

30 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
