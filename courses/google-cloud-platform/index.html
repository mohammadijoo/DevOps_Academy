Course brief

A comprehensive Google Cloud curriculum for DevOps engineers building secure, automated, observable, resilient, and cost-efficient application platforms.

This course is organized as a progressive operational curriculum. Lesson files are reserved in the repository structure so future content can be added without changing URLs or navigation.

By the end

You will be able to

  • Design Google Cloud organizations, projects, identity, networks, compute, storage, and application platforms
  • Operate GKE, Cloud Run, serverless workloads, databases, and event-driven systems
  • Build delivery pipelines with Cloud Build, Artifact Registry, Cloud Deploy, GitHub, and GitOps
  • Automate infrastructure with Terraform, Config Connector concepts, and policy controls
  • Apply Google Cloud Well-Architected, SRE, security, resilience, governance, and FinOps practices

Complete syllabus

61 chapters in prerequisite order.

The structure goes beyond a service catalog and includes architecture, identity, security, networking, delivery, observability, reliability, governance, automation, cost, troubleshooting, and production operations.
