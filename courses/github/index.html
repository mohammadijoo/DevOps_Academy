Course brief

A complete GitHub curriculum for collaborative software delivery and platform governance.

This course is organized as a progressive operational curriculum from fundamentals through advanced production practice. Lesson files are reserved with stable repository paths so content can be added later without changing URLs or navigation.

By the end

You will be able to

  • Organize repositories, teams, issues, pull requests, projects, and releases
  • Build secure CI/CD workflows with GitHub Actions and reusable automation
  • Apply rulesets, review policies, environments, OIDC, and least privilege
  • Use Dependabot, code scanning, secret scanning, and artifact attestations
  • Automate GitHub through the CLI, REST/GraphQL APIs, Apps, and webhooks

Complete syllabus

32 chapters in prerequisite order.

The structure goes beyond command references and feature lists. It includes architecture, security, reliability, troubleshooting, automation, governance, performance, and realistic production workflows.
